# Phone app (GitHub Pages)

The phone app is the same single-page app as the Claude artifact, built into `app/dist/` and published on GitHub Pages. You open it in the phone browser and use "Add to Home screen" so it behaves like an app.

## Publish it

1. Create a GitHub repository and push this folder to `main`.
2. In the repository: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Push any change. The workflow `.github/workflows/pages.yml` runs `scripts/build_app.py` and deploys `app/dist`.
4. Open `https://<your-user>.github.io/<repo>/` on the phone. In Chrome: menu → **Add to Home screen** (or Install app).

To build and test locally, run `python scripts/build_app.py` and open `app/dist/index.html` in a browser.

## What works without the AI

Almost everything, offline after the first load:

- Flashcards with spaced repetition, "I already know this", section progress, pacing, weekly review, the log, backups, text-to-speech, read-aloud check.
- **Placement check**: built on the phone from the word lists (meaning, reverse lookup, listening, kanji readings) plus a fixed grammar bank (`languages/<code>/grammar/question-bank.json`) and, for Japanese, conjugation questions. A new mix each time.
- **Japanese conjugation drill**: generated by rule from the N5–N3 verb list (`languages/ja/grammar/verbs.json`) and a fixed adjective list. Mixed rounds lean on the forms you miss most.
- **Japanese exceptions drill**: dates, months, counters, time and age words and special readings from a fixed table.
- **Writing and speaking prompts**: from `languages/<code>/prompts.json` and your current words.
- **Corrections without a key**: "Copy for my Claude project" copies the task and your answer in the project's own format (`zh · writing · correct this …`). Paste it into the project chat.

## What still uses AI (optional key)

Only the parts that need new open-ended text, where nothing free gives the same quality:

| Feature | Why it stays AI |
|---|---|
| Writing and speaking correction in the app | Marking free text needs a language model. Without a key, use "Copy for my Claude project". |
| Reading and listening passages | Fresh passages with questions; there is no free bank at these levels. |
| Grammar sets, weak-point blitz, weekly re-test | Questions written around your own mistakes. The fixed bank is too small for daily drilling. |
| Mock exams | Full papers in the official structure. |
| "Make one" / "New example" on a card | Example sentences are written only when you press the button, never in the background. |

Free chat and explanations moved to the Claude project chat, which is included in your plan and knows your profile. The in-app chat and the "Add 10 words" generator were removed (the library already has about 17,000 words, and import still works).

## AI is optional, and there is a free option

The app never asks for a key with a pop-up. Paste one on the Today screen (AI key card) if you want the AI parts.

| Key | Provider | Cost |
|---|---|---|
| Any key that does not start with `sk-ant-` (Google keys usually start with `AIza`) | Google Gemini API | Free tier from Google AI Studio (aistudio.google.com, "Get API key"). No card. Limited requests per minute and per day, and free-tier requests may be used by Google to improve its products. Check the limits shown in AI Studio. |
| Starts with `sk-ant-` | Anthropic API | Paid, billed to your account |

- **Free path:** create the Gemini key and paste it in the AI key card on the Today screen. If a call fails with "model not found", Google renamed the model: set `laoshi_gemini_model` in the browser's local storage to a current Flash model name.
- **No-cost alternative with better quality:** do the AI work in the Claude project chat or the Claude artifact, which use your existing Claude plan, and use the phone app only for cards, progress and backups.
- **Never put a key in the repository or the page.** The GitHub Pages site is public. Remove the key from a browser with `claude.forgetKey()` in the console or by clearing site data.

## Where your progress lives

In the phone browser's local storage, per device and per browser. There is no account sync in the standalone version. Use **Export log** in the Log tab for the corrections. To move progress between devices, copy the data from the browser (a full backup/restore button is planned). Clearing site data deletes progress.

## Updating vocabulary

Edit or add JSON files in `languages/<code>/vocab/`, run `python scripts/build_app.py`, commit, push.

## Known limits

- Speech recognition depends on the browser (Chrome on Android works; some browsers have none). Keyboard dictation always works.
- Text-to-speech quality depends on the voices installed on the phone.
- The official sample audio files are not included (they are large). Play them from the files on your phone while you do the sample papers.
