# Japanese exam structures (JLPT)

Modelled on the official JLPT layout; counts and timings approximate. Pass marks: N5 80, N4 90, N3 95, N2 90, N1 100 out of 180, each section also has a minimum.

Part codes: yomi = kanji reading, hyouki = orthography, gokei = word formation, bunmyaku = context vocabulary, ruigi = close meaning, youhou = usage, gram1 = grammar form, gram2 = sentence composition (star), gram3 = text grammar, readS = short reading, readM = medium reading, readL = long reading, readX = integrated reading, readC = claim comprehension, readI = information retrieval, task = task comprehension, point = point comprehension, gist = gist comprehension, express = situational expression, response = quick response, listenX = integrated listening
